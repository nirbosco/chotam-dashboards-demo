# Chotam Dashboards · Demo

Anonymized demo of Chotam's internal field-companion dashboard system.

**Live demo**: https://nirbosco.github.io/chotam-dashboards-demo/

## What this is

A demo, fully anonymized, of the internal information system used by Chotam (חותם) field companions in their day-to-day work with municipalities and schools. The real system shows real data under full access controls. This demo presents the same UI with fictional data for capability demonstration.

## Two views

1. **מבט רשות** · Municipality-wide view: nine schools in a cycle, presence, climate, team responsibility, alerts, success stories, AI cross-cutting insights.
2. **מבט מנהלת** · School principal view: today's pulse, weekly calendar, leading team status, student lens, six-dimensional school depth (agency, belonging, collective responsibility, parent engagement, distributed leadership, relationships).

## Tech

React + Vite + Tailwind + Recharts. RTL, Hebrew, Rubik typography.
